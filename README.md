Snake i Python

Et enkelt Snake-spill laget i Python. Prosjektet ble laget for å øve på grunnleggende programmering, brukerinput, kollisjon og enkel spilltilstand.

Om prosjektet
Spillet er en klassisk versjon av Snake der spilleren styrer en slange rundt på skjermen, samler mat og prøver å unngå å krasje i vegger eller seg selv.

Målet med prosjektet var ikke å lage et avansert spill, men å få mer praktisk erfaring med hvordan et lite program kan bygges opp steg for steg.

Teknologi: Python, INF100 Graphics

Kjøre prosjektet
Prosjektet krever Python og INF100 Graphics-biblioteket.
Installer avhengigheter hvis prosjektet har en requirements.txt-fil:
pip install -r requirements.txt

Start spillet:
snake_main.py

Hva jeg lærte
Gjennom prosjektet fikk jeg øvd på:
å håndtere tastaturinput
å tegne enkel grafikk
å bruke en spill-løkke
å oppdatere posisjon og retning
å sjekke kollisjon
å holde styr på poeng
å strukturere et lite Python-prosjekt


Prosjektet er et lite læringsprosjekt og kan kjøres lokalt.
